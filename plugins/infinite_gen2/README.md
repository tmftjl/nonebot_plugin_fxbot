# 无限二代（FxBot 适配）

来源：https://github.com/muchen712/dsh-infinite-gen-2/tree/master ，上游插件版本 0.2.3，MIT 许可。
原版提示词随包保存在 `resources/infinite_gen2.prompt`，运行时不联网下载或执行上游脚本。

这是提示词注入，不是修改模型或解除服务端限制，不保证有效。启用会增加输入 token，
并可能影响既有人格、语气和回答质量。

首次部署后重启 FxBot，在控制台「无限二代」中打开「启用无限二代」并保存。
配置命名空间为 `infinite_gen2`，内容为 `{"enabled": false, "direct_llm": false}`，默认关闭。
「纯人格直聊」开关也在同一张卡片里：打开后所有会话改用直聊管线，与提示词开关相互独立。
开关全局生效，保存后从下一次组装提示词开始生效；已经组装或开始生成的请求不受影响。
关闭后不再追加提示词，但不会清空已有对话历史。

使用独立的 `system_prompt` hook，以 `order=100` 在人格解析之后、阶段任务规则之前注入上游原文。
普通规划、被动规划、Focus 共享规划和回复均生效；Focus 的各聊天参考资料不重复注入。
“纯人格直聊”也保留此插件：开启插件时，将原文直接拼接在人格后，随后发送短期历史和当前消息，
不恢复 Planner、工具、记忆或普通回复任务模板。直聊使用 `phase="direct_reply"` 的系统段扩展。
不作用于独立子代理或其他非聊天模型调用，不改变会员闸门、命令权限、工具权限或模型路由。
没有移植 Harness 专用查询工具和客户端状态条；该状态条仅按关键词猜测是否拒绝，
不能验证模型限制是否被解除。

上游提示词与许可见资源文件及本目录 `LICENSE`。
